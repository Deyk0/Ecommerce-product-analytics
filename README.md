# E-commerce Product Analytics

## О проекте

Учебный проект по продуктовой аналитике интернет-магазина.

Цель проекта — проанализировать поведение пользователей, продуктовую воронку, активность, удержание и монетизацию, а также сформировать продуктовые выводы на основе данных.

Проект выполнен с использованием PostgreSQL, SQL и Python.

## Цели анализа

В рамках проекта были исследованы:

- продуктовая воронка от визита до покупки;
- конверсия между этапами воронки;
- DAU, WAU и MAU;
- stickiness (DAU/MAU);
- когортный анализ и retention;
- purchase retention;
- выручка и динамика продаж;
- AOV и ARPPU;
- покупки на пользователя;
- накопленная выручка на платящего пользователя;
- распределение пользователей по сегментам накопленной выручки;
- конверсия по устройствам;
- конверсия по источникам трафика;
- повторные покупки;
- время до второй покупки.

## Данные

Для проекта был создан синтетический датасет интернет-магазина.

Основные сущности:

- 50 000 пользователей;
- 500 товаров;
- 204 837 событий;
- 19 303 заказа.

Основные таблицы PostgreSQL:

- `users`
- `products`
- `events`
- `orders`

События пользователей:

- `visit`
- `view_product`
- `add_to_cart`
- `checkout`
- `purchase`

## Основные результаты

### Воронка

| Этап | Пользователи |
|---|---:|
| Visit | 39 473 |
| Product View | 36 025 |
| Add to Cart | 25 914 |
| Checkout | 19 602 |
| Purchase | 16 278 |

Общая конверсия от визита до покупки — **41,24%**.

Наибольшее снижение наблюдается между просмотром товара и добавлением в корзину. Конверсия View → Cart составила **71,93%**.

### Активность

MAU вырос с примерно **6,2 тыс. пользователей в январе** до примерно **9 тыс. пользователей в марте**, после чего стабилизировался на близком уровне.

Средний DAU/MAU в течение наблюдаемого периода находился примерно в диапазоне **4,3–4,8%**.

### Retention

Для анализа использовались 30-дневные периоды:

- M0 — 0–29 дней;
- M1 — 30–59 дней;
- M2 — 60–89 дней;
- M3 — 90–119 дней.

Для январской когорты:

- M0 — 80,34%;
- M1 — 10,29%;
- M2 — 0,63%.

Последние когорты имеют неполный период наблюдения, поэтому их поздний retention нельзя напрямую сравнивать с более ранними когортами.

### Монетизация

- Общая выручка — **601,15 млн**;
- количество заказов — **19 303**;
- средний чек — **31 142,97**;
- ARPPU — **36 930,39**.

### Выручка по категориям

Наибольшую долю выручки генерирует категория **electronics — 52,23%**.

Далее:

- home — 16,33%;
- sports — 11,35%;
- clothing — 8,61%;
- accessories — 5,38%;
- beauty — 4,61%;
- books — 1,49%.

### Повторные покупки

- 2 676 пользователей совершили минимум две покупки;
- доля повторных покупателей среди покупателей — **16,44%**;
- среднее время до второй покупки — **15,39 дня**;
- медианное время — **14,11 дня**.

Большая часть повторных покупок происходит в первые 30 дней после первой покупки.

### Накопленная выручка на платящего пользователя

Для платящих пользователей рассчитана накопленная выручка за весь наблюдаемый период.

Среднее значение — **36 930,39**.

Распределение выручки между пользователями неоднородно: небольшая доля высокоценных пользователей формирует значительную часть общей выручки.

## Продуктовые гипотезы и направления для дальнейшего анализа

На основе результатов можно исследовать:

1. причины снижения конверсии View → Cart;
2. влияние цены и категории товара на вероятность добавления в корзину;
3. поведение пользователей перед первой покупкой;
4. причины низкой доли повторных покупателей;
5. факторы, влияющие на вероятность второй покупки;
6. поведение высокоценных пользователей;
7. различия между источниками трафика;
8. гипотезы по увеличению конверсии и повторных покупок с помощью A/B-тестов.

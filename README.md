# E-commerce Product Analytics

## О проекте

Проект по продуктовой аналитике интернет-магазина.

Цель проекта — проанализировать поведение пользователей, продуктовую воронку, пользовательскую активность, удержание и монетизацию, а также сформировать продуктовые выводы и гипотезы на основе данных.

Проект выполнен на синтетическом датасете с использованием PostgreSQL, SQL и Python.

## Цели анализа

В рамках проекта исследованы:

* продуктовая воронка от визита до покупки;
* конверсия между этапами воронки;
* DAU, WAU и MAU;
* stickiness (DAU/MAU);
* когортный анализ и retention;
* выручка и динамика продаж;
* AOV и ARPPU;
* количество покупок на пользователя;
* повторные покупки;
* время до второй покупки;
* конверсия по устройствам;
* конверсия по источникам трафика;
* A/B-тест изменения конверсии View Product → Add to Cart.

## Данные

Для проекта был создан синтетический датасет интернет-магазина.

Основные сущности:

* 50 000 пользователей;
* 500 товаров;
* 209 105 событий;
* 20 482 заказа;
* период наблюдения: январь — июнь 2025 года.

Основные таблицы PostgreSQL:

* `users`
* `products`
* `events`
* `orders`

События пользователей:

* `visit`
* `view_product`
* `add_to_cart`
* `checkout`
* `purchase`

Пользователи также разделены на две группы для A/B-теста:

* `control`
* `test`

## Основные результаты

### Продуктовая воронка

Последовательная воронка:

**Visit → Product View → Add to Cart → Checkout → Purchase**

| Этап         | Пользователи |
| ------------ | -----------: |
| Visit        |       39 461 |
| Product View |       36 109 |
| Add to Cart  |       27 041 |
| Checkout     |       20 591 |
| Purchase     |       17 181 |

Общая конверсия от визита до покупки составила **43,54%**.

Конверсия между основными этапами:

* Visit → Product View — **91,51%**
* Product View → Add to Cart — **74,89%**
* Add to Cart → Checkout — **76,15%**
* Checkout → Purchase — **83,44%**

### Пользовательская активность

За период анализа:

* средний DAU — около **378 пользователей**;
* максимальный DAU — **467 пользователей**;
* MAU вырос с **6 111 пользователей в январе** до **9 161 в марте**;
* в дальнейшем MAU находился примерно в диапазоне **8,8–9,2 тыс. пользователей**.

DAU/MAU в течение периода находился примерно в диапазоне **4,35–4,75%**.

### Retention

Для когортного анализа использовалась помесячная когорта регистрации.

Для январской когорты:

* M+0 — **80,10%**;
* M+1 — **9,82%**;
* M+2 — **0,57%**;
* M+3 — **0,01%**.

Для последних когорт поздние периоды наблюдения отсутствуют, поэтому их retention не сравнивался напрямую с полностью наблюдаемыми когортами.

### Повторные покупки

За период анализа:

* **2 903** пользователя совершили минимум две покупки;
* доля повторных покупателей среди платящих пользователей — **16,90%**;
* среднее время до второй покупки — **15,35 дня**;
* медианное время — **14,08 дня**.

Распределение времени до второй покупки:

* 0–7 дней — **18,05%**;
* 8–14 дней — **31,38%**;
* 15–30 дней — **43,16%**;
* 31–60 дней — **7,30%**;
* более 60 дней — **0,10%**.

Таким образом, основная часть повторных покупок происходит в течение первых 30 дней после первой покупки.

## A/B-тест

В проекте проведён A/B-тест изменения пользовательского сценария на этапе:

**View Product → Add to Cart**

Единицей анализа выступала сессия.

| Группа  | Просмотрели товар | Добавили в корзину | Конверсия |
| ------- | ----------------: | -----------------: | --------: |
| Control |            29 137 |             17 436 |    59,84% |
| Test    |            28 743 |             19 520 |    67,91% |

Разница между группами составила **+8,07 п.п.**

Относительное увеличение конверсии — **+13,49%**.

Для проверки статистической значимости был рассчитан z-score:

**z = 20,21**

Полученное значение соответствует очень малой вероятности случайного наблюдения такой разницы при отсутствии эффекта. В рамках проекта результат используется как статистическое обоснование для дальнейшего исследования тестируемого изменения.

## Продуктовые гипотезы и направления для дальнейшего анализа

На основе проведённого анализа можно исследовать:

1. причины потерь пользователей между просмотром товара и добавлением в корзину;
2. влияние цены и категории товара на вероятность добавления в корзину;
3. различия поведения новых и возвращающихся пользователей;
4. причины низкой доли повторных покупателей;
5. факторы, влияющие на вероятность второй покупки;
6. поведение пользователей с высокой суммарной выручкой;
7. влияние источника привлечения на долгосрочную ценность пользователя;
8. повторное проведение A/B-тестов для проверки продуктовых гипотез.

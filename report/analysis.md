\# Аналитический отчёт — E-commerce Product Analytics



\## 1. Цель проекта



Цель проекта — провести продуктовый анализ данных интернет-магазина и определить основные точки роста продукта.



В рамках проекта были проанализированы:



\* пользовательская активность;

\* воронка продаж;

\* удержание пользователей;

\* выручка и заказы;

\* повторные покупки;

\* сегменты пользователей;

\* результаты A/B-теста.



Основной фокус — использование SQL и Python для поиска закономерностей и формирования продуктовых гипотез.



\---



\## 2. Ключевые результаты



За период с января по июнь 2025 года:



\* 50 000 пользователей;

\* 209 105 событий;

\* 20 482 заказа;

\* общая выручка — 601,04 млн;

\* средний чек — 29 344,98;

\* 17 181 пользователь совершил хотя бы одну покупку;

\* доля повторных покупателей — 16,90%;

\* среднее время до второй покупки — 15,35 дня;

\* конверсия Visit → Purchase — 43,54%.



В A/B-тесте конверсия из просмотра товара в добавление в корзину выросла с 59,84% до 67,91%.



\---



\## 3. Воронка продаж



Для анализа была построена последовательная воронка:



\*\*Visit → Product View → Add to Cart → Checkout → Purchase\*\*



| Этап         | Пользователи | Конверсия от предыдущего этапа |

| ------------ | -----------: | -----------------------------: |

| Visit        |       39 461 |                           100% |

| Product View |       36 109 |                         91,51% |

| Add to Cart  |       27 041 |                         74,89% |

| Checkout     |       20 591 |                         76,15% |

| Purchase     |       17 181 |                         83,44% |



Общая конверсия от посещения до покупки составила \*\*43,54%\*\*.



Наибольшее снижение количества пользователей наблюдается на переходе от просмотра товара к добавлению в корзину.



Это может указывать на потенциальную точку роста, связанную с карточкой товара, ценой, условиями покупки или интерфейсом добавления товара в корзину.



При этом для подтверждения причины необходим дополнительный анализ поведения пользователей.



\---



\## 4. Пользовательская активность



Среднее количество активных пользователей в день составило около \*\*378 DAU\*\*.



Максимальное значение DAU за период — \*\*467 пользователей\*\*.



MAU увеличился с:



\* 6 111 пользователей в январе;

\* до 9 161 пользователя в марте.



После марта показатель оставался примерно на сопоставимом уровне.



Отношение DAU/MAU находилось в диапазоне:



\*\*4,35–4,75%\*\*



Это показывает относительно невысокую частоту ежедневного использования продукта.



В дальнейшем можно отдельно исследовать причины невысокой частоты возвращения пользователей.



\---



\## 5. Retention



Для анализа удержания пользователей были сформированы когорты по месяцу первой активности.



Для январской когорты:



| Период | Retention |

| ------ | --------: |

| M+0    |    80,10% |

| M+1    |     9,82% |

| M+2    |     0,57% |

| M+3    |     0,01% |



Для февральской когорты значения были сопоставимыми:



\* M+0 — 80,35%;

\* M+1 — 9,94%;

\* M+2 — 0,47%;

\* M+3 — 0,01%.



Основное снижение происходит уже после первого месяца.



Это может говорить о том, что значительная часть пользователей не формирует долгосрочную привычку возвращаться в продукт.



Для дальнейшего анализа стоит исследовать:



\* причины ухода пользователей;

\* различия между новыми и возвращающимися пользователями;

\* влияние источника трафика;

\* связь повторных покупок и retention.

\## 6. Монетизация



За анализируемый период:



\* выручка — \*\*601,04 млн\*\*;

\* количество заказов — \*\*20 482\*\*;

\* средний чек — \*\*29 344,98\*\*;

\* платящих пользователей — \*\*17 181\*\*;

\* ARPPU — \*\*34 983,05\*\*.



\### Выручка по месяцам



Выручка постепенно увеличивалась в течение первых месяцев и достигла максимального значения в июне — около \*\*108,3 млн\*\*.



Средний чек при этом оставался относительно стабильным и находился примерно в диапазоне \*\*28,8–30,3 тыс.\*\*



Это означает, что рост выручки в основном связан с увеличением количества заказов, а не с существенным ростом среднего чека.

\## 9. A/B-тест



В рамках проекта был проведён A/B-тест изменения на этапе:



\*\*Product View → Add to Cart\*\*



Единицей анализа была выбрана сессия.



| Группа  | Просмотрели товар | Добавили в корзину | Конверсия |

| ------- | ----------------: | -----------------: | --------: |

| Control |            29 137 |             17 436 |    59,84% |

| Test    |            28 743 |             19 520 |    67,91% |



Разница между группами:



\*\*+8,07 п.п.\*\*



Относительный рост конверсии:



\*\*+13,49%\*\*



Для проверки статистической значимости был рассчитан z-score:



\*\*20,21\*\*



Полученное значение указывает на статистически значимое различие между группами.



При этом статистическая значимость сама по себе не показывает экономический эффект изменения. В реальном продукте дополнительно необходимо оценивать влияние теста на:



\* количество заказов;

\* выручку;

\* средний чек;

\* повторные покупки;

\* другие продуктовые метрики.

\## 10. Продуктовые гипотезы



На основании проведённого анализа можно сформировать несколько гипотез для дальнейшей проверки.



\### Гипотеза 1. Улучшение карточки товара



Проблема:



На этапе Product View → Add to Cart происходит одно из наиболее заметных снижений количества пользователей.



Гипотеза:



Если улучшить карточку товара — фотографии, описание, информацию о доставке, цене и условиях покупки — пользователи будут чаще добавлять товар в корзину.



Метрика:



\*\*View Product → Add to Cart Conversion\*\*



\---



\### Гипотеза 2. Напоминание о повторной покупке



Проблема:



Большинство повторных покупок происходит в течение первых 30 дней.



Гипотеза:



Если отправлять пользователям персонализированные напоминания и рекомендации в этот период, доля повторных покупок может увеличиться.



Метрики:



\* Repeat Purchase Rate;

\* Retention;

\* Revenue per User.



\---



\### Гипотеза 3. Работа с источниками трафика



Проблема:



Конверсия между источниками трафика отличается незначительно.



Гипотеза:



Одной конверсии недостаточно для оценки качества каналов. Возможно, источники с похожей конверсией существенно отличаются по повторным покупкам и выручке.



Для проверки необходимо сравнить источники по:



\* стоимости привлечения;

\* ARPPU;

\* повторным покупкам;

\* retention;

\* LTV.

\## 11. Ограничения анализа



В рамках проекта использовались синтетические данные, поэтому результаты не являются реальными показателями интернет-магазина.



Основные ограничения:



\* данные сгенерированы искусственно;

\* отсутствуют реальные затраты на привлечение пользователей;

\* отсутствуют данные о маржинальности товаров;

\* нет информации о возвратах;

\* нет данных о реальных маркетинговых кампаниях;

\* A/B-тест основан на смоделированных данных.



Поэтому выводы проекта используются прежде всего для демонстрации подхода к продуктовому анализу.
